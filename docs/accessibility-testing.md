## 行為測試項目

鍵盤與焦點：

- 每頁只有一個一級標題（8 頁，淺色與深色）
- 第一個 Tab 停在「跳到主要內容」，啟動後焦點移到主要內容
- 所有可聚焦元素都有可見的焦點樣式
- 對話框開啟時焦點在「取消」；按 Esc 關閉後，焦點回到觸發按鈕
- 從工作台進入案件時，焦點在「處理動作」標題
- 重設資料後，焦點移到「模擬資料已重設」訊息

表單：

- 空白送出時焦點移到錯誤摘要，摘要列出 7 個必填欄位
- 錯誤欄位標記 `aria-invalid`，錯誤訊息以 `aria-describedby` 連到欄位
- 點錯誤摘要中的連結，焦點跳到該欄位
- 選擇服務後，自動帶出負責單位（以 `output` 元素播報）
- 送出成功後，焦點移到「通報已送出」
- 處理動作表單有錯誤時，焦點移到第一個錯誤欄位

動態內容：

- 套用篩選後，焦點移到結果標題（標題包含件數）
- 排序後焦點留在同一個排序按鈕，欄位有 `aria-sort`，並以狀態訊息播報排序結果
- 處理動作完成後，焦點移到結果訊息

流程：

- 通報、評估分級、提供替代管道、回報修正、複驗未通過退回、再修正、複驗通過結案，以及逾期督促，全部可以完成
- 處理歷程完整記錄每一步

其他：

- 320 像素寬度下，首頁、通報、案件查詢、儀表板都不需要水平捲動整頁
- 頁面地標數量適中（版頭、導覽、主要內容、版尾與搜尋）
- 直接開啟檔案（file://）時，首頁與案件查詢也能讀到模擬資料
- 沒有 JavaScript 錯誤
